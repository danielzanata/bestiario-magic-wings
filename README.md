# Bestiário Magic Wings

Consulta rápida de monstros, itens, cartas, builds, comida e lendários do jogo Magic Wings.
Site estático (HTML + JSON), sem servidor. Projeto de fã, não oficial.

Os dados vêm dos endpoints públicos do próprio jogo (app.magicwings.online). As imagens são dos ícones públicos do jogo.
Algumas contas e estimativas foram deduzidas dos dados e estão marcadas como tal na própria página.
